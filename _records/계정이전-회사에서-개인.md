## 변경점
- **GitHub**: 회사 계정 `ahnjoohwan` → 개인 계정 `johnnyahn` 으로 이전.
  - 개인 계정에 새 private repo `johnnyahn/thumbnail-tool` 생성, 전체 커밋 이력 push.
  - 로컬 `origin` 원격을 `https://github.com/johnnyahn/thumbnail-tool.git` 로 변경.
  - `gh`에 개인 계정 추가(`gh auth login`) 후 active 계정으로 사용.
- **Vercel**: 회사 팀 프로젝트(`team_aVEZ3uPrpHmXNySbrJn4rZIb`) → 개인 계정으로 이전.
  - 회사 팀의 기존 프로젝트 삭제 → 개인 Vercel에서 `johnnyahn/thumbnail-tool` 새로 Import.
  - 프로덕션 도메인을 다시 `thumbnail-tool-public.vercel.app` 로 지정(자동 생성된 임시 도메인 제거).
  - 로컬의 회사 프로젝트용 `.vercel/` 링크 제거(gitignore라 repo 영향 없음).
- **AdSense**: 환경변수 `NEXT_PUBLIC_ADSENSE_CLIENT=ca-pub-3705778855053595`, `NEXT_PUBLIC_ADSENSE_SLOT=8431689204` 설정 후 Redeploy. 게시자 스크립트 + 광고 슬롯이 라이브 번들에 정상 반영됨 확인.

## 이유·맥락
- 개인 프로젝트인데 배포/저장소가 회사 계정에 묶여 있어 개인 계정으로 정리.
- **도메인을 동일하게(`thumbnail-tool-public.vercel.app`) 유지한 이유**: AdSense 사이트 심사·확인은 도메인 단위라, 주소가 바뀌면 새 사이트로 재심사가 필요할 수 있음. 계정/프로젝트가 바뀌어도 도메인 문자열만 같으면 AdSense는 영향 없음.
- `NEXT_PUBLIC_*` 변수는 빌드 시점에 인라인되므로, 값 추가 후 **Redeploy(빌드 캐시 미사용)** 가 반드시 필요.

## 영향 / 후속
- 앞으로 push는 `gh` active 계정이 `johnnyahn`인 상태에서 수행해야 개인 repo로 들어감. 빠른 전환용 alias를 `~/.zshrc`에 추가: `ghme`(개인 johnnyahn), `ghwork`(회사 ahnjoohwan), `ghwho`(현재 활성 계정 확인).
- 개인 프로젝트는 브라우저로 열 때 Naver Whale 사용(개인 계정 분리).
- **AdSense env 설정 주의(겪은 실수)**: `NEXT_PUBLIC_*`는 빌드 시점에 코드에 인라인됨. ① 값 변경 후 반드시 **"Use existing Build Cache" 해제**로 Redeploy해야 새 값이 클라이언트 번들에 박힘(캐시 켜면 옛 청크 재사용). ② SLOT 추가하려다 CLIENT 값을 슬롯 번호로 덮어쓰는 실수 → CLIENT=`ca-pub-...`, SLOT=숫자, **두 변수로 분리** 설정해야 함. 검증은 라이브 HTML의 `adsbygoogle.js?client=` 값과 `/_next/static/chunks/*.js` 번들에 client/slot 문자열이 박혔는지로 확인.
- **회사 repo 처리**: `ahnjoohwan/thumbnail-tool`은 회사 동료들이 사용하므로 **유지(삭제 안 함)**. 동료가 쓰는 배포는 별도 `thumbnail-tool-gamma.vercel.app`로 개인 작업과 완전히 분리됨. 개인 수정은 개인 repo에만 반영(평소대로 `git push`).
- **남은 작업**: `NEXT_PUBLIC_ADSENSE_SLOT`까지 설정 완료. 실제 광고 노출은 AdSense 사이트 심사 승인 이후.
